# Security

## Supported versions

SDK Toolbox is at 0.x. Security fixes go into the latest release only.

| Version | Supported |
|---|---|
| 0.0.x (latest) | yes |

## Reporting a vulnerability

Please don't open a public issue. Report it privately, either through GitHub's [private vulnerability reporting](https://github.com/JustSteveKing/sdk-toolbox/security/advisories/new) or by email to steve@juststeveking.com.

Include the version, a description of the problem, and if you can, the smallest connector and request that reproduce it. Once there's a fix, it's released with a GitHub security advisory crediting you, unless you'd rather not be named.

## What the defaults protect against

[docs/security.md](docs/security.md) describes what the toolbox does to keep credentials, requests and stored data safe, so you can tell what counts as a vulnerability: any way around those protections does.
